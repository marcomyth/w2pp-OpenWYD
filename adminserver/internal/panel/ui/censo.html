Item no WYD não tem identidade: um item é um índice mais três pares de efeito, e duas unidades iguais são indistinguíveis. Não dá para perguntar este aqui é cópia de qual. Dá para perguntar quantos existiam antes e quantos existem agora.

A contagem separa por refino, e é isso que a torna útil: ninguém dupa espada +0. Trinta unidades a mais no refino 0 é gente farmando; catorze a mais no refino 11 é outra conversa.

O que este número não diz

Três limites, ditos aqui para não serem descobertos no meio de uma investigação.

  • Só enxerga o que foi salvo. Não existe save periódico: item chega no banco no logout. Quem está online há três dias tem o inventário de três dias atrás aqui dentro. Um item pode “aparecer” hoje só porque o dono finalmente saiu do jogo.
  • Drop de monstro não é registrado. Crescimento de item comum não tem explicação nenhuma nesta tela, e é por isso que existe o filtro de refinado.
  • A leitura útil é a tendência. O pulo de um dia pode ser uma guilda inteira saindo junto do jogo. O mesmo índice subindo todo dia por uma semana é outra coisa.
